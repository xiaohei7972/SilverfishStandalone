# Third-party provenance and licensing

This first implementation contains original foundation code and no copied historical Silverfish sources.

Before importing any Silverfish source, record the exact upstream repository, commit, file path, author notices and applicable license. The HB community repository includes a GPL-3.0 license file; this fact alone does not establish the licensing status of each imported historical component. Do not copy private Hearthbuddy/Triton assemblies, GreyMagic binaries or game assets.

Libmem.NET is an independent CardResearchLab package licensed AGPL-3.0. Any future combined distribution must account for the obligations of every included component. No project-wide license is asserted in this new repository until the owner selects and reviews an appropriate license and source provenance.

Sources to check:
- https://github.com/CardResearchLab/Libmem.NET
- https://github.com/ChuckHearthstone/SilverFish
- https://github.com/lijhnihaoa/HB

Compliance review should precede code import or public release, not follow it.
