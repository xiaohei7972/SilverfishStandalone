# SilverfishStandalone

An independent, testable Hearthstone decision-analysis host built with .NET 8.

Work in progress: the architecture separates game-state acquisition, strategy computation, and presentation. The historical Silverfish algorithm will be integrated only after a dependency and license audit. No Hearthbuddy/Triton binaries are required by this repository.

See the `feat/standalone-foundation` branch for the initial implementation.
